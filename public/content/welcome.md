# Hello

내 첫 GitHub Pages 사이트를 React와 Markdown 뷰어 구조로 옮겼습니다.

## 문서 추가 방법

1. `public/content` 아래에 `.md` 파일을 추가합니다.
2. `public/content/index.json` 에 문서 정보를 등록합니다.
3. 배포 후 목록에서 문서를 클릭하면 같은 페이지에서 본문을 볼 수 있습니다.

## 예시 코드

```bash
npm install
npm run dev
```
